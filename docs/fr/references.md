# Références et portée

Sources primaires consultées le 2026-10-08. Les liens externes sont explicites et ne chargent aucune ressource automatiquement.

<h2 id="git-worktree">Git worktree</h2>

Classification: `tool-reference`. [Git worktree](https://git-scm.com/docs/git-worktree).

Separate working trees share repository objects and refs; they are not a security sandbox.

<h2 id="git-merge-base">Git merge-base</h2>

Classification: `tool-reference`. [Git merge-base](https://git-scm.com/docs/git-merge-base).

--is-ancestor distinguishes ancestry, with exit 1 for false and other errors handled separately.

<h2 id="python-unittest">Python unittest</h2>

Classification: `tool-reference`. [Python unittest](https://docs.python.org/3/library/unittest.html).

Tests prove explicit scenarios, not completeness.

<h2 id="python-statistics">Python statistics</h2>

Classification: `tool-reference`. [Python statistics](https://docs.python.org/3/library/statistics.html#statistics.median).

Median calculation does not establish a representative sample.

<h2 id="wcag22">WCAG 2.2</h2>

Classification: `external-standard`. [WCAG 2.2](https://www.w3.org/TR/WCAG22/).

Normative accessibility reference; this corpus makes no conformance certification.

<h2 id="diataxis">Diátaxis</h2>

Classification: `recommendation`. [Diátaxis](https://diataxis.fr/).

Documentation framework, not an external engineering standard.
